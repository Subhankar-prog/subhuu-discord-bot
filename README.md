# 👑 Subhuu Bot

The ultimate, all-in-one custom Discord bot. Built with Discord.js v14 and Express.

## ✨ Features
* 🛡️ **Advanced Auto-Mod:** Anti-spam timeouts, anti-phishing regex, and full audit logging.
* 🎰 **Casino Economy:** Daily rewards, blackjack, slots, coinflip, and a custom server shop.
* 📈 **Leveling System:** Gain XP from chatting and hanging out in Voice Channels.
* 🎵 **Music Player:** High-quality playback from YouTube/Spotify with custom playlists.
* 🤖 **AI Integration:** Chat with ChatGPT (`/ask`) and generate stunning art (`/imagine`).
* 🎛️ **Web Dashboard:** Control everything without writing a single line of code.

## 🚀 Deployment
This bot is designed to be hosted 24/7 on services like Render, DigitalOcean, or Oracle Cloud.

1. Clone this repository.
2. Run `npm install` to install all dependencies.
3. Create a `.env` file with your tokens.
4. Run `npm start` (or `node index.js`).
